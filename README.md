## Featured Project

### OU Applied Statistics Capstone Portfolio Project

I am rebuilding my OU applied statistics capstone as a reproducible portfolio project using R, Git/GitHub, modular scripts, and eventual Shiny deployment.

The project analyzes public felony case records from Cleveland County, Oklahoma, with attention to sentencing outcomes, attorney type, and related case characteristics.

The goal is to demonstrate applied statistics, ethical interpretation of observational data, reproducible workflow design, model interpretation, and clear communication of quantitative findings.
